## Coherent journal backup

As the service user, create a mode-0700 backup directory on protected storage. Run `python3 scripts/backup.py /var/lib/secretary/secretary.sqlite3 /protected/backup/secretary-YYYYMMDD.sqlite3`. The script opens SQLite read-only, uses SQLite's backup API (including committed WAL content), checks integrity, and publishes the completed snapshot without overwriting an existing destination. It closes SQLite handles and converts the snapshot to DELETE journal mode before publication, leaving a standalone file without temporary WAL/SHM sidecars. It neither copies a live database file nor removes the source WAL. Keep backup permissions private, define retention, and encrypt off-host storage before copying sensitive journals. Configuration/secret backups require separate protected handling; ordinary logs and repository artifacts must exclude them.
