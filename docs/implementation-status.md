## Implemented behavior

The owner explicitly retained FSM + one in-process command bus for lightweight operation. [ADR0001](adr/0001-lightweight-command-bus-and-operation-fsm.md) records the decision. Read and write handlers share dispatch; there is no separate query bus, event broker, replicated read store, projection worker or event-sourced model.

The plugin exposes 26 Sheets, Docs, report, reminder and shared-history tools. Rust Core retains domain/application/infrastructure/presentation layers, typed command dispatch and a durable SQLite operation FSM. Transient preview state is limited to 64 entries and 4 MiB serialized JSON per host API, pruned on preview/approval activity without background timers. Evicted previews need fetching again; already-open dialogs retain their immutable snapshot. Core operation history is unaffected. Controlled writes use immutable previews, separate operator approval, owner/digest/action binding, single-use commits, conflict checks and explicit reconciliation after uncertain provider outcomes. Reminder operations use OpenClaw's native Gateway and retain canceled/completed jobs for history.

Generic Sheets `grid` views are bounded ranges with typed values and source references, read-only by default. T027 permits one literal rectangle of at most 100 cells only within an explicitly registered `writable_range`, through preview/approval and observation-only uncertain recovery. Formula, merge, header and structured-view targets are protected. Docs supports registered tab reads and preview/approval/apply for plain-text append or one exact replacement. Unsupported rich structures/suggestions fail closed for editing. Rich formatting, new spreadsheet/Docs file creation and arbitrary grid writes are outside this slice. See [Workspace capabilities](specs/workspace-capabilities.md).

Personal memory is owned by OpenClaw. The plugin has no memory tools or preference store. The host template requests FTS-only retrieval and three primary-memory results; these are resource-conscious defaults, not measured savings or a hard token cap. Core's SQLite journal stores operation state, not personal memory.
