# T027 — Controlled literal edits in registered Sheets grids

Status: specification in progress; implementation not yet started. Owner selected local development of grid cell/range editing; VPS clone/installation remains deferred.

Use existing sheets_preview_change/action=update and sheets_update, with a distinct journal resource kind preserving legacy digests. A grid view must explicitly register a writable_range contained in its existing read range; absent permission remains read-only. Model input supplies one A1 rectangle and a complete rectangular matrix, at most 100 cells. Permit text/numbers/booleans and explicit null clearing; strings beginning '=' stay literal, never formulas. Reject formula, merged and registered protected-header targets. No schema-free append, insert/delete rows, formatting or arbitrary batch bodies.

Immutable preview binds sheet ID/title, registered view/permission, A1 target, complete raw entered values before/after, owner, expiry, mapping version and source fingerprint. Current target and source must still match before one native batchUpdate/updateCells with userEnteredValue-only field mask. No retries after ambiguous/interrupted outcomes: shared journal recovery and operator reconcile observe state only. Observation proves current intended state, not attribution. Google lacks atomic compare-and-swap; a concurrent edit after preflight can still race, so limits must be explicit.

Use the previously agreed public Core/bus/HTTP, real Google HTTP adapter/synthetic provider and plugin approval seams. Tests must cover denied permissions/bounds, protected cells, typed literals/clearing, full approval binding, stale source/registry, replay and lost-response restart/reconciliation with one send. Actual SDK/locks remain mandatory. Keep examples/production flags disabled, existing workbook unchanged, and local/synthetic/live evidence separate. Final acceptance requires implementation, relevant/full local checks, per-commit low-effort review, synchronized sources and integration commit. No live action or automatic access grant is authorized.
