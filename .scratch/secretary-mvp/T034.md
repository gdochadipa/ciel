- Same offline binary: `registry diff --before BASE --after CANDIDATE --output REPORT` (fixed order, private paths only). Reuse actual Registry deserialization/validation and bounded <=1 MiB regular/no-final-symlink/nonblocking reads for both inputs.
- Pure comparison matches Sheets/Docs by exact alias and views by (spreadsheet alias, view name). Ignore ordering of resource lists, view lists and JSON object keys; preserve all other declared fields/values. Alias/name renames are removals+additions; do not infer renames. Normalize existing defaults through the actual typed Registry, not a substitute schema.
- Terminal JSON reports only aggregate added/removed/modified counts for spreadsheets/documents/views, version_changed, mappings_changed and version_change_required. No IDs/aliases/titles/paths/version values/raw diagnostics. configuration_changed=false, report_created=true, live_access_checked=false and activation_changed=false. Exit0 means comparison/report creation succeeded, not host eligibility.
- Private report format_version1 contains before_version, after_version, the same summary and changes.spreadsheets/documents arrays. Each changed resource has key(alias), change(added/removed/modified), before/after normalized full registration (null on missing side). Views are sorted by name inside those registrations, and their aggregate counts track definition changes only, not inherited parent access. Full before/after data exposes all target/range/permission/schema changes for deliberate local review. Treat the report as private configuration, never Git/console output.
- Equal versions are allowed for inspection; mappings_changed with unchanged version sets version_change_required=true. A version-only change yields no registration changes. No-op comparison still produces a report. These flags do not qualify actual access/global writes/approval or compare against the running service.
- Validate both inputs and build/cap the entire serialized report <=1 MiB before exclusive Unix0600-or-stricter output creation. Reuse no-overwrite/symlink/output-alias protection; errors leave inputs intact, no output before validation. Output overflow rejects with registry_too_large rather than truncating; write/disk failure can leave a partial new report as in init/add.
- No env/credential loading, Google/network, journal/listener, active config install/reload/activation or plugin tool additions (26 retained). Preserve previous CLI behavior and personal workbook. No dependencies, services or paid quota added.
